# 配液计算器

手机上的配液计算工具。省掉「查分子量 → 翻公式 → 按计算器」这三步。

配一个溶液本来要：上数据库查分子量 → 翻本子找公式 → 按计算器 → 还可能按错。
这个工具让你只填**浓度**和**体积**，它直接告诉你**称多少克**。

---

## 怎么开始用

**下载 → 解压 → 双击 `index.html`。就这三步。**

1. 本页右上方绿色的 **Code** 按钮 → **Download ZIP**
2. 下载到的 zip 文件上**右键 → 解压**
   （⚠️ 别直接在压缩包里双击 `index.html`，那样打不开）
3. 进解压出来的文件夹，**双击 `index.html`**

浏览器会打开它，可以开始算了 —— 不用装软件、不用注册、不用配置任何东西。

> **想让手机也能开、想发给同学？** 看下面的[让手机和实验室都能用](#让手机和实验室都能用)。
> 五分钟能弄完，不用会编程。

## 它能算什么

| 模块 | 用途 |
|---|---|
| **快速配液** | 给浓度和体积，算出该称多少克。支持单个算 / 攒一张清单一次配多个 |
| **缓冲体系 pH** | 温度换算（给一个温度下的 pH，求另一个温度下该调到多少）；多质子酸按 Henderson-Hasselbalch 算盐比 |
| **体系配置** | 一个溶液里配好几个组分（比如培养基、PBS），每个组分给目标浓度，分别算固体质量或母液取量 |
| **母液稀释** | 从母液配工作液，算取多少母液、补多少溶剂 |

浓度单位支持摩尔浓度（M / mM / μM）、质量浓度（mg/mL）、百分比（%）、倍数（×），
**单位会自动换算** —— `1 M` 和 `1000 mM` 是同一个东西，不用自己换算。

算完可以**一键复制成操作步骤的文本**（「称取 NaCl 2.92 g，溶于 50 mL 水」），
贴进实验记录本或者发给别人。

算过的会自动存进**历史记录**，可以打标签归类（比如都标上「配胶」），以后点标签就能翻出来。

## 导入你自己的试剂表

**这一步最值得做。**

不导入也能用 —— 常用试剂已经内置了 28 种，查不到的会联网去公开数据库查。
但导入你自己那张表之后：

- 常用试剂**不联网就能查到**，快很多，断网也能用
- 结果里会显示**它在哪个位置**（你的柜子、你的编号）
- **可以直接用中文名查** —— 你的表里怎么写，就怎么查

### 怎么导

打开「设置 → 我的试剂表」。

**最快的办法**：在 Excel 里选中你的表格区域，`Ctrl+C`，粘到那个框里，点「预览」。

粘之前不用改格式。第一行写列名，之后每行一个试剂。认得出这些列名（中英文都行）：

| 列 | 说明 |
|---|---|
| **中文名** | 和英文名至少要有一个 |
| **英文名** | 同上。两个都有最好 —— 联网查分子量时用英文名最准 |
| **分子量** | 有它才能算称量 |
| **CAS** | 可选。有了它，输 CAS 号也能查到你表里的中文名和位置 |
| **位置** | 可选。你的货位编号，比如 `A-99` |
| **分组** | 可选。哪个柜子/哪个架子，比如 `通风橱`、`4℃冰箱` |
| **分子式**、**品牌**、**溶剂**、**备注** | 都可选，会显示在结果里 |

没有列名也没关系 —— 那就按这个顺序读：
`中文名 / 英文名 / 分子量 / CAS / 位置 / 分组 / 分子式 / 品牌 / 溶剂 / 备注`

**没有分子量的行也能导入**，只是那种试剂查得到位置、算不了称量。
**没写名字的行会被跳过**，预览里会告诉你跳过的是第几行，照着回去改就行。

导入前一定会先给你看**预览** —— 识别到几条、哪几行有问题。你点了确认才真的存进去。

> ⚠️ 你的试剂表存在**你自己的浏览器里**，不会上传到任何地方。
> 但也正因为这样：**清浏览器数据、换浏览器、换电脑、开无痕模式，都会没有。**
> 原始 Excel 一定留着，重新导一次就行。

### 也可以传 CSV 文件

不想复制粘贴的话，把表格另存成 CSV 再上传。两种存法：

**方法一：Excel 另存为**

1. 打开 Excel 文件
2. 点 **文件 → 另存为**
3. 「保存类型」选 **CSV UTF-8（逗号分隔）(\*.csv)**
   - 表格里只有英文和数字的话，选 **CSV（逗号分隔）** 也可以
   - **有中文就一定要选 CSV UTF-8**，否则会乱码
4. 选保存位置，点保存
5. Excel 会提示「可能包含不兼容的功能」，点**是**

> ⚠️ 注意：「另存为」之后如果你又点了「保存」，**当前文件会变成 CSV 格式**，
> 原来的 Excel 格式（比如公式、格式、多个工作表）就丢了。保险起见先复制一份再操作。

**方法二：WPS 表格**

操作和 Excel 基本一样：**文件 → 另存为 → 文件类型选 CSV → 保存**。

## 中文名识别（可选，不填也能用）

内置的对照表只覆盖常用试剂。表外的中文名（比如「十二水合磷酸氢二钠」），
可以在**设置 → 中文名识别**里填一家大模型服务商的 API Key，让它认一下。

支持硅基流动、智谱、DeepSeek、通义千问、Kimi。硅基流动和智谱有**免费额度**可以用。

**这里有个刻意的设计**：AI **只回答一个问题** —— 「这个名字英文叫什么」。
它给的名字或 CAS 号，会被拿去公开数据库（PubChem / NCI Cactus）查分子量。

所以：

- AI 认错了 → 那个名字在数据库里查不到 → **显示「查不到」，让你手填**
- AI **没有任何机会**输出一个被当成分子量用的数字

这是它敢接 AI 的全部理由 —— 分子量错了是要称错药的，不能让模型编。

结果卡上会显示「识别为 `xxx`」并带一个 `AI` 小标，就是让你核对它认成了什么。

> 🔒 API Key 存在你自己的浏览器里，请求直接从浏览器发给你选的服务商，不经过任何中间服务器。
> 但**别在公用电脑上填**。

## 让手机和实验室都能用

上面那样双击打开，只能在这台电脑上用。想让手机上也能开、想发给同学，
需要把它变成一个网址 —— 这个过程叫「部署」，**不用会编程，五分钟能弄完**。

### 最省事：Netlify（拖一下就完事）

1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)
2. 把**解压出来的那个文件夹**整个拖进网页里
3. 等几秒，它会给你一个网址，形如 `https://随机名字.netlify.app`

把这个网址发给同学、存到手机书签里就行。

不用注册就能先看效果；想保留这个网址、想改成好记的名字，注册一下（免费）即可。
以后想更新，把文件夹重新拖一次就会覆盖。

> 上传的就是那个文件夹本身 —— 它已经是完整可用的网站，不需要任何「构建」步骤。

**手机上打开后可以加到主屏幕**，用起来跟 App 一样：

- iPhone：用 **Safari** 打开 → 点底部分享按钮 → 「添加到主屏幕」
- 安卓：用 **Chrome** 打开 → 右上角菜单 → 「添加到主屏幕」

### 如果你有 GitHub 账号

**连起来自动部署**（以后改了代码，push 一下网站自动更新）：

1. 把仓库 fork 到你自己的 GitHub
2. [Netlify](https://app.netlify.com) → **Add new site** → **Import an existing project** → 选 GitHub → 选这个仓库
3. 构建设置全部留空：
   - Build command：**留空**
   - Publish directory：**`.`**（就是仓库根目录）
4. 之后每次 `git push`，Netlify 会自动重新部署

**或者用 GitHub Pages**（不用 Netlify）：
仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
一两分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

## 常见问题

**双击 `index.html` 打开是白屏、没反应？**

最常见的原因是**没解压** —— 在压缩包里直接双击会打开一个临时文件，用不了。先解压再打开。
已经解压了还是白屏，换个浏览器试试（Chrome、Edge、Safari 都行）。

**查不到我的化合物？**

按这个顺序排查：

1. 内置的只有 28 种常用试剂，其他会**联网查**（所以要能上网）。
2. 用**中文名**查不到？到设置里开「中文名识别」，它能认出大部分中文名。
3. 联网也查不到（冷门试剂、混合物、自配的东西）？可以用**手动填分子量** —— 结果卡上有入口。

**算出来的分子量和瓶子上写的不一样？**

水合物的分子量是最容易出错的（把十二水合物的值写成无水物的，很常见）。
本工具用分子式 + 原子量**逐位反算**，你可以自己核对一遍。
真要是工具算错了，欢迎反馈 —— 但**配液请以试剂瓶标签为准**。

**我导入的试剂表会丢吗？**

会，如果清了浏览器数据。它只存在你自己的浏览器里，不上传。
所以：**原始 Excel 留着**，丢了重新导一次就行（一分钟的事）。

**我不懂技术，能部署吗？**

能。走上面「最省事：Netlify」那条路 —— 全程只需要拖一个文件夹，连注册都不用。

### 这个仓库不需要构建

仓库根目录就是可以直接发布的站点 —— 改完代码刷新一次就能看到。
Service Worker 是「网络优先」策略，不用手动清缓存。

```bash

node tools/check-reagents.js # 拿 NCI Cactus 交叉核对内置试剂库的分子量
```

### 代码结构

```
index.html          单页骨架，所有视图都在这一个文件里
css/app.css         全部样式，:root 里是设计 token
js/
  calc.js           计算引擎（纯函数，无 DOM / 网络 / 存储，Node 直接可跑）
  units.js          单位换算与格式化
  data-reagents.js  内置试剂库（28 条，含多形式）
  data-buffers.js   缓冲体系 pKa 数据
  data-zh.js        常用试剂的中英对照
  inventory.js      试剂位置表（内置数据 + 用户导入 的合并加载器）
  inventory-import.js  用户表格的解析器（纯函数）
  lookup.js         查询降级链：内置库 → 位置表 → 缓存 → PubChem / Cactus
  store.js          localStorage 封装（缓存 / 历史 / 标签 / 设置）
  ui.js             DOM 小工具
  app.js            所有界面逻辑
tools/              验收、图标生成脚本
```

所有 `js/*.js` 都是 UMD 写法（既能在浏览器里用 `<script>` 加载，也能被 Node `require`），
所以 `tools/verify.js` 可以直接把它们 require 进来测，不用起浏览器。

### 三条设计上的取舍

**1. 不引入任何第三方库。**
CSV 解析、图标生成（手写 PNG）、Service Worker 都是自己写的。
代价是多写了些代码，换来的是没有供应链风险、没有构建步骤、clone 下来就能跑。

**2. pKa 用 25 °C 无限稀释的热力学值，不内置经典速查表。**
那张常见的速查表用的是表观 pKa（磷酸约 6.80），和热力学值（7.20）系统性差 43%。
总浓度超过 0.1 M 时界面会提示离子强度的影响。

**3. 分子量一律用分子式 + IUPAC 原子量反算。**
不直接抄数据库里的分子量 —— 水合物的分子量数据库经常搞错（写成无水物的值）。
反算出来的可以逐位核对。
